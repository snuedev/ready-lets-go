# Ready Let's Go
Helps a traveller decide what to take on a trip: describe the trip, get a list of what to pack, adjust it to suit yourself, tick it off as you go.

## Setup

Firebase and Neon accounts are set up by running `./scripts/setup-services.sh`,
which walks the consoles step by step and writes the values it captures into
`.env`. See `.env.example` for what ends up there.
